# FACE-RECOGNITION-DOOR-LOCK
This project is a Face Recognition Door Lock using an AI-Thinker ESP32 CAM. It is designed to recognize authorized faces and unlock a door using a servo motor. An unknown face can activate a buzzer. The project includes coding, face recognition research, circuit design, and documentation.

Features
- Face detection and recognition
- Authorized user recognition
- Servo-controlled door lock
- Buzzer for unknown visitors

 Hardware
- AI-Thinker ESP32-CAM
- Servo motor
- Buzzer
- Push button
- Power supply

Current Progress
- Project idea and research completed
- Circuit designed in Fritzing
- ESP32-CAM CameraWebServer code studied
- Face recognition software development started
- Servo and buzzer control planned
